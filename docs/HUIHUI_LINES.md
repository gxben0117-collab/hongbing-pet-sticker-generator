# 灰灰專屬台詞設計

版本：v1.33

## 角色定位

灰灰是 7 歲男生灰虎斑貓，核心語氣是活潑、調皮、愛出去玩、會巡邏、偶爾撒嬌，並保留貓咪視角的幽默感。

固定意象：

- 灰灰本人稱呼
- 出門、巡邏、窗邊、陽台
- 罐罐、飯飯、零食
- 紙箱、沙發、地板、尾巴
- 摸頭、蹭蹭、呼嚕

## 新增分類

| 分類 | 用途 |
| --- | --- |
| 灰灰日常 | 一般聊天、回家、窗邊待命、佔地盤 |
| 灰灰出門 | 出門玩、巡邏、探路、回家報平安 |
| 灰灰吃飯 | 開飯、罐罐、零食、補給 |
| 灰灰撒嬌 | 摸頭、抱抱、蹭蹭、呼嚕 |
| 灰灰吐槽 | 傻眼、無言、撇清責任、貓式吐槽 |
| 灰灰工作 | 監工、會議、確認、任務完成 |
| 灰灰安慰 | 陪伴、休息、鼓勵、給力量 |
| 灰灰節日 | 祝福、拜年、慶祝、好運 |
| 灰灰短句 | 高頻短回覆 |

## 使用建議

- 做 16 格主題包時，可直接選「灰灰專屬」群組後按隨機填入。
- 做日常實用包時，選「灰灰生活應用」。
- 做撒嬌或陪伴包時，選「灰灰情緒陪伴」。
- 若要保持貼圖文字清楚，優先使用 2 到 6 字短句。
