## 🔄 文檔更新

文檔應該隨著專案更新而更新。當有重大變更時：

1. 更新相關文檔
2. 在 Git commit 中註明文檔更新
3. 確保文檔與代碼保持同步

## 📝 文檔規範

- 使用 Markdown 格式
- 中文文檔使用繁體中文
- 保持文檔結構清晰
- 添加適當的標題和章節
- 使用表格、列表等提高可讀性
